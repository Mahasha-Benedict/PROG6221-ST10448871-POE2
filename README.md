Cybersecurity Awareness Chatbot - South Africa

Project Overview
A WPF-based cybersecurity awareness chatbot designed to in order educate the South African citizens about online threats, including phishing, password safety, scams, privacy protection, and malware.
The Features are:
- Voice greeting at startup
- ASCII art logo display
- Keyword recognition for 8+ cybersecurity topics
- Random varied responses for engaging conversations
- Follow-up handling ("tell me more", "another tip")
- User memory (stores name and favorite topics)
- Sentiment detection (worried, curious, frustrated)
- Professional error handling
- Dark theme WPF interface

Technologies Used
- C# .NET 8.0
- WPF (Windows Presentation Foundation)
- System.Media for audio playback
- GitHub Actions for CI/CD

Prerequisites
- Visual Studio 2022 with .NET desktop development workload
- .NET 8.0 SDK
